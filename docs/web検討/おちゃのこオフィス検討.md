## おちゃのこオフィスでしか使えない機能 (6項目)

### 1. おちゃのこAPI

| 項目 | 詳細 |
|------|------|
| **何ができるか** | 外部システムからHTTP経由で商品情報・在庫・価格・受注データにアクセス |
| **認証** | Bearer Token (管理画面で発行) |
| **データ形式** | JSON |

**APIエンドポイント一覧:**

| エンドポイント | メソッド | 機能 | 上限 |
|-------------|---------|------|------|
| `/v1/products` | GET | 商品一覧取得 (在庫数含む) | 1,000件/回 |
| `/v1/products/{id}` | GET | 商品詳細取得 | - |
| `/v1/products` | PUT | 在庫数変更 | 1,000件/回 |
| `/v1/products` | PUT | 価格変更 | 1,000件/回 |
| `/v1/orders` | GET | 受注一覧取得 | 1,000件/回 |
| `/v1/orders/{id}` | GET | 受注詳細取得 | - |

**トレカエルバフにとっての価値:**

| 用途 | 現在の方法 (オフィスなし) | API利用時 (オフィスあり) |
|------|------------------------|----------------------|
| 商品検索 | `/product-list` HTMLをスクレイピング → 正規表現でパース | `GET /v1/products` → 構造化JSON |
| 在庫チェック | 商品ページHTMLをfetch → 正規表現で「在庫数」「売切」パース | `GET /v1/products/{id}` → `stock` フィールド |
| 価格取得 | HTMLから `¥(\d+,\d+)` を正規表現抽出 | `GET /v1/products/{id}` → `price` フィールド |
| 在庫更新 | おちゃのこ管理画面で手動 or MycalinksPOS自動同期 | `PUT /v1/products` → プログラムで自動更新も可能 |

### 6. 専用アカウント

- おちゃのこオフィスの機能のみ利用できる専用アカウントを作成可能

- ショップ管理画面へのフルアクセス権限を与えずに運用可能

## 契約する利点まとめ

### Firebase移行に必須

| 利点 | 詳細 |
|------|------|
| **HTMLスクレイピング廃止** | 正規のAPI (JSON) で商品データ・在庫を取得。現在の正規表現パースが不要に |
| **GAS全廃の前提条件** | Firebase Hostingに移行すると、別ドメインからOCNK商品ページへの直接fetchはCORSでブロックされる。APIならCloud Functionsからサーバーサイド呼び出しが可能 |
| **安定性向上** | HTMLスクレイピングはOCNKのデザイン変更で壊れるリスクがある。APIは仕様が固定 |
| **パフォーマンス向上** | HTML全体を取得→パースより、JSON APIの方が高速・軽量 |

### EC運営業務の効率化

| 利点 | 詳細 |
|------|------|
| **帳票一括出力** | 受注にチェック → PDF一括出力。手書きや個別作成が不要 |
| **送り状連携** | CSV出力でゆうパックプリントRに取り込み → 伝票番号自動更新 |
| **メルマガ改善** | 購入履歴で顧客セグメント → ターゲット配信。HTMLメールで視覚的に訴求 |
| **スタッフ委任** | 専用アカウントで出荷スタッフに必要な機能のみ提供 |

### 将来の拡張

| 利点 | 詳細 |
|------|------|
| **在庫自動更新** | `PUT /v1/products` で在庫数をプログラムから変更可能。将来の自動化に |
| **価格自動更新** | `PUT /v1/products` で価格をプログラムから変更可能。相場連動価格設定に |
| **受注データ取得** | `GET /v1/orders` で受注を外部システムに取り込み。売上ダッシュボード構築に |
| **MycalinksPOS代替** | 将来的にPOS→OCNK在庫同期を自前で構築する場合に必要 |

## 契約しない場合のリスク

| リスク | 影響 |
|--------|------|
| **Firebase移行が不完全** | 商品検索・在庫チェック機能をFirebase Hostingで動かせない (CORSブロック) |
| **HTMLスクレイピング維持** | OCNK側のデザイン変更で壊れる可能性。保守コストが高い |
| **フリーページ依存継続** | カスタム機能の一部をOCNKフリーページに残す必要があり、FTP/管理画面でのアップロードが継続 |
| **GAS廃止不可** | 一部GAS (商品データ取得関連) を廃止できない |

## コスト比較

| 方式 | 月額コスト | 管理負荷 |
|------|----------|---------|
| **現状 (GAS + OCNK フリーページ)** | 0円 (追加費用なし) | GAS/Spreadsheet管理 + FTPアップロード + フリーページ編集 |
| **Firebase + おちゃのこオフィス** | **660円** | Firebase管理のみ。OCNK管理画面は商品登録/受注処理のみ |

**660円/月で、GAS全廃 + FTP不要 + HTMLスクレイピング廃止 + 安定したAPI利用が実現。**
